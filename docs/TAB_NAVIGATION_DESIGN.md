# 底部导航重设计方案 · 5 Tab

> 状态：✅ 决策定型（D1–D4 全部确认 · 2026-05-26）
> 日期：2026-05-26
> 背景：当前 3 Tab（首页/闻思/复习）随新功能上线已不够用；「修持/班级/我的」隐藏在首页卡片和头像入口，发现性差。

---

## 一、方案总览

### 当前 vs 新设计

```
当前（3 Tab）                    新设计（5 Tab）
─────────────────────            ─────────────────────────────────────
[ 首页 ][ 闻思 ][ 复习 ]         [ 首页 ][ 闻思 ][ 修持 ][ 班级 ][ 我的 ]
```

### Tab 定义

| # | Tab | 路由根 | 图标语义 | 核心用户动作 |
|---|---|---|---|---|
| 1 | **首页** | `/` | 莲花 / 今日 | 看今天是什么日子、快速进入任务、签到 |
| 2 | **闻思** | `/courses` | 法本 / 书 | 读法本（法本子Tab）、答题复习（复习子Tab）、写笔记 |
| 3 | **修持** | `/practice` | 念珠 | 记录念诵、修持愿进度、打卡历史 |
| 4 | **班级** | `/class` | 人群 / 共修 | 看主班动态（可切班）、参加法会共修、讲考 |
| 5 | **我的** | `/me` | 头像 | 个人信息、各类历史记录、设置、通知 |

### Tab 1 · 首页 `/`

**定位**：仪式感入口，每天打开 App 的第一眼。

**现有内容（保留）**：
- 全屏画报背景（admin 上传月度图 · 渐变兜底）
- 顶部：头像（→ 我的 Tab）+ 藏历日期区域（→ `/calendar`）+ 活动药丸（→ 班级 Tab）
- streak 徽章（🔥 N 天）

**底部卡片区域（✅ D4 确认：保留原 4 卡样式不变）**：

原 4 卡保持磨砂玻璃 2×2 布局，内容和跳转不变：

```
┌──────────────────────────────────────────┐
│ [📖 闻思  60%]     [🎓 班级  广论班]      │
│ [✓  练习  10题]    [📿 修学  计数 ]      │
└──────────────────────────────────────────┘
```

**今日状态卡片（✅ D2 确认：签到放首页 · 新增在 4 卡上方）**：

在原 4 卡上方插入 1 张全宽「今日修学卡」，整体样式与 4 卡一致（磨砂玻璃），
首页整体画报背景、顶部区域、streak 徽章均不变。

```
┌──────────────────────────────────────────┐  ← 今日修学卡（全宽）
│ 今日修学                                  │
│ 《广论》第3课 · 已读 60%    [ 继续 → ]    │
│ 修持：今日 216 遍  ✓        签到：[ 签到 ]│
└──────────────────────────────────────────┘
┌──────────────────────────────────────────┐  ← 原 4 卡（不变）
│ [📖 闻思  60%]     [🎓 班级  广论班]      │
│ [✓  练习  10题]    [📿 修学  计数 ]      │
└──────────────────────────────────────────┘
```

- 今日修学卡数据来源：闻思进度（现有）+ 今日 PracticeLog 汇总（新）+ 签到状态（新）
- 已签到时：签到按钮变为「✓ 已签到」灰态
- 未开始闻思：显示「今天还没有闻思记录」+ [ 开始 → ]
- 点击卡片左区 → 跳闻思 Tab；点击右区「签到」按钮 → 原地签到（不跳页）

**Tab 触发 TabBar 显示的路由**：仅 `/`（画报风格独立，不做二级嵌套）

### Tab 4 · 班级 `/class`

**定位**：社群维度入口——班级动态、法会共修、讲考。

**当前问题**：`/class/:id` 是二级路由，没有对应的班级根路由，Tab 点击无处落。

**新增根页面 `/class`**（需新建，✅ D3 确认：默认主班 + 切换入口）：

```
┌─────────────────────────────────────┐
│  班级                  [ 切换班级 ↓] │  ← 多班时显示切换按钮
│                                     │
│  《广论》2026 春季班                  │
│  第 12 周 · 辅导员：法明师兄          │
│  [ 进入班级详情 → ]                  │
│                                     │
│  ── 法会 / 共修 ──────────────────── │
│  🪷 极乐法会  进行中                  │
│  5月28日 – 6月3日                   │
│  我的发愿：金刚萨埵 10,800 遍         │
│  [ 查看 ]                           │
│                                     │
│  📿 周日共修  3天后                  │
│  本周日 18:00                        │
│  [ 查看 ]                           │
│                                     │
│  ── 班级动态 ──────────────────────  │
│  法明师兄  今日累计 108 遍  👍 随喜   │
│  阿弥师兄  已完成今日签到   👍 随喜   │
└─────────────────────────────────────┘
```

**切换班级行为**（多班用户）：
- 点「切换班级 ↓」→ 弹出底部 Sheet，列出用户所在的全部班级
- 选择后：整个班级 Tab 的内容切换为该班数据（不改变 isPrimary，只是 Tab 内的显示班级）
- 每次重新进入班级 Tab，默认恢复主班（`isPrimary=true`）

**无班级时**：
- 显示引导卡：「还没有加入班级」+ [ 输入邀请码 → /join-class ]

**路由归属（TabBar 显示）**：
- `/class`（新根页）· `/class/:id` · `/class/:id/sessions` · `/class/:id/sessions/:sid`
- `/class/:id/ranking` · `/class/:id/meditations` · `/class/:id/practice-ranking`
- `/events` · `/events/:id`（法会从独立路由归入班级 Tab 高亮）
- `/assemblies/:id`

**活动药丸（首页右上角）**：保留，点击跳到 `/class`（Tab 4）而不是 `/events`。

**功能入口归属说明**：
- 法会：`/class` 根页面「法会区块」→ 「查看」→ `/events/:id`；「查看更多」→ `/events` 列表
- 共修：`/class` 根页面「共修区块」→ 「去签到」→ `/class/:id/sessions/:sid`
- **讲考（决策 2026-05-26）**：`/class` 根页面 → 「进入班级详情」→ `/class/:id` 班级详情页内「讲考区块」→ `/class/:id/sessions`；**不在 /class 根页面单独显示**

## 三、TabBar 显示 / 隐藏规则

**显示 TabBar 的路由根**（替代现有 3 个）：

| Tab | 匹配规则 |
|---|---|
| 首页 | `pathname === '/'` |
| 闻思 | `pathname.startsWith('/courses')` 或 `/quiz` 或 `/notes` 或 `/mistakes` 或 `/favorites` 或 `/sm2-review` |
| 修持 | `pathname.startsWith('/practice')` 或 `/me/meditations` |
| 班级 | `pathname.startsWith('/class')` 或 `/events` 或 `/assemblies` |
| 我的 | `pathname.startsWith('/me')` 或 `/profile` 或 `/notifications` 或 `/settings` 或 `/about` 或 `/help` |

**隐藏 TabBar 的路由**（沉浸式阅读 / 播放场景）：
- `/read/:slug/:lessonId`（法本阅读 · 全屏）
- `/meditation/:id`（观修播放 · 全屏）
- `/quiz-practice` · `/quiz/:lessonId`（答题 · 专注模式）
